# Referencias documentales

Estas imágenes se generan con el fixture sintético E2E y se comparan de forma exacta después de rasterizar la primera página a 96 dpi. Cubren Carta horizontal para el SOP y Carta vertical para la evaluación.

La retícula, colores, jerarquía y alineación se derivaron de los PDF operacionales entregados por el usuario. El logotipo empleado es el activo Arauco local del proyecto, convertido a PNG para compatibilidad confiable con el renderizador PDF.

Si un cambio visual es deliberado, se debe revisar la salida impresa, reemplazar la referencia correspondiente y dejar constancia en el cambio OpenSpec.
