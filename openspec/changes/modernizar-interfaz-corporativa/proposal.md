# Modernizar interfaz corporativa

## Problema

La aplicación combina estilos verdes heredados con la paleta corporativa, generando diferencias visuales entre navegación, formularios, informes, documentos y Carta Gantt.

## Solución

Implementar un sistema visual transversal basado en `#696158`, `#BFB800`, `#EA7600` y `#DFD1A7`, con superficies, contrastes, espaciado, estados interactivos y comportamiento responsive coherentes.

## Alcance

- Navegación lateral, encabezado, inicio y autenticación.
- Formularios, pestañas, tablas, tarjetas, informes, estados vacíos y modales.
- Integración visual con Carta Gantt sin modificar su lógica.
- Preservación de los estilos específicos de impresión.
